How saving works

This page stores its data in project-checklist.json, next to this page in the project folder. Once the file is linked, every change saves to it automatically.

Several people can use the same project at once. The page checks the file every 20 seconds and whenever you switch back to it, and it merges everyone's changes. Nobody's notes get overwritten.

For security, browsers ask you to approve file access once per session. That's the yellow Reconnect bar you may see when you open the page.

Automatic saving needs Microsoft Edge or Google Chrome. In other browsers, use ••• › Download a copy and Load from a .json file.
